# CogSeed 电信行业经营决策 Agent——开发验证交接清单 v0.6

## 1. 本轮要验证什么

不是只验证一个聊天机器人，而是验证完整实训闭环：

```text
在线使用Agent/Skill/RAG工具
→ 生成项目资产
→ 编排工作流
→ 跑通电信经营决策Demo
→ 提交项目快照
→ 老师运行并评审
```

## 2. 开发读取顺序

1. `00_business_brief.md`：先理解运营商组织、岗位、指标、案例根因和Agent边界；
2. `README.md`：理解试验目标和运行方法；
3. `01_requirements.md`：理解产品范围与验收口径；
4. `02_prompts.md`：配置构建工具和业务Agent；
5. `03_demo_fixture.json`：注入固定脱敏事实；
6. `04_decision_response_schema.json`：约束结构化输出；
7. `05_expected_first_response.json`：核对标准首轮结果；
8. `09_user_interactive_demo.html`：核对最终用户体验；
9. `08_test_record.md`：记录实际结果与证据。

## 3. 最短开发路径

### 第一步：先验证最终Agent

- 配置提示词P-01、P-02；
- 注入脱敏场景JSON；
- 开启结构化输出Schema；
- 输入首问；
- 对比标准首轮输出。

### 第二步：做企业级对话工作台

- 只读取DecisionResponse；
- 先以业务用户身份操作`09_user_interactive_demo.html`，再实现会话列表、组织范围、连续消息流、建议追问和输入框；
- 将判断、根因、行动、验证、反馈和证据抽屉嵌入Agent回答；
- 不让Renderer二次调用模型。

### 第三步：补多轮

- 先支持为什么、到人、积分、What-if、调整、blocked六类；
- 前端保存conversation_id、snapshot、revision、branch和feedback。
- 普通追问只向消息流追加delta回答，不重复首轮完整结果。

### 第四步：外包一层实训工作台

- Agent构建器调用P-03；
- Skill构建器调用P-04；
- RAG构建器调用P-05；
- 工作流编排调用P-06；
- 老师评审助手调用P-07。

### 第五步：闭合提交评审

- 提交时冻结Agent、Skill、RAG、Workflow、TestRun和Demo结果；
- 老师只能评审提交快照；
- 老师可一键运行7个标准问题；
- AI建议评分，老师最终确认。

## 4. 首轮必须通过的测试

```text
分析一下当前网格人员配置是否合理？
为什么不是缺人？
具体到谁，应该怎么安排？
装维A的积分怎么算？
如果增加一名装维会怎样？
调整：营销C本周不可用。
只有平均积分，直接告诉我应该重派谁。
```

## 5. 企业级对话界面必须通过的检查

- 使用固定演示员工账号可以进入工作台；
- 错误账号或密码显示明确提示；
- 顶部和侧栏显示员工姓名、工号、角色和组织范围；
- 退出登录能够返回登录页；
- “新建经营分析”可点击，并在最近会话新增记录；
- 新建会话后追问、反馈和依据展开状态被重置；
- 首屏是对话工作台，不是独立仪表盘；
- 左侧有最近会话和当前数据范围；
- 顶部有会话标题、组织路径和数据状态；
- 用户问题与Agent回答在同一连续消息流中；
- 首轮回答内呈现经营判断、指标、根因、行动和验证；
- 快捷追问、手工输入和回车发送进入同一会话；
- 普通追问仅追加增量回答；
- 登录后无需滚动即可看到建议追问、输入框和发送按钮；
- 长对话仅滚动消息区，底部输入区始终可见；
- 唯一的“查看完整判断依据”入口可展开10人判断和积分分账；
- 采纳、调整、驳回只记录待确认状态；
- 桌面端和390px宽度均无横向溢出。

`09_user_interactive_demo.html`使用固定脱敏数据和本地交互逻辑，是目标体验与测试口径，不是CogSeed实现完成证据。可双击`start.command`本地运行；最终仍必须在CogSeed应用预览中实际运行并保留截图或录屏。

## 6. 本地验证命令

```bash
python3 outputs/validate_cogseed_telecom_demo.py \
  outputs/CogSeed电信经营决策Agent_脱敏演示场景数据_v0.1.json \
  outputs/CogSeed电信经营决策Agent_标准首轮输出_v0.1.json
```

预期：

```text
PASS: fixture_people=10 | signals=5 | root_causes=2 | actions=2 | response_mode=full
```

## 7. 演示完成门

- 学员确实在线操作过Agent、Skill、RAG工具；
- 项目资产栏能看到相应版本；
- 工作流显示资产已串联并运行成功；
- 最终应用支持企业级连续对话、首轮结构化结果和多轮增量回答；
- CogSeed实际运行效果与参考HTML的核心信息结构一致；
- 提交后老师可看到同一资产快照和运行结果；
- 老师能评分、写评语和退回/通过；
- 页面标识“脱敏演示案例”，不宣称生产验证。
