# 电信经营决策 Agent · 端到端实训试点

本仓库用于“电信经营决策实训·挑战③”的作品交付与核验。所有业务数据均为脱敏演示案例，不代表真实组织或员工的经营事实。

**当前版本：场景与运行证据初稿，尚不是可独立运行的应用发行包，尚未完成 EduSeed 提交或教师评审。**

## 当前包含

- `scenario/`：业务说明、需求、提示词、脱敏数据、DecisionResponse Schema 和交接清单，来自用户提供的 v0.6 试验包。其中的功能要求是目标，不代表全部已实现。
- `evidence/response-01.json` 至 `response-08.json`：本机 CogSeed 实际模型响应的结构化提取结果。
- `evidence/validation-results.json`：上述响应的既有校验记录，包含首问、What-if、人员不可用、证据不足拦截和积分追问。8 份提取结果通过 Schema；部分原始回答带围栏，`pure_json=false`，不能据此声称原始输出始终为纯 JSON。
- `manifest.json`：本版本文件的 SHA-256，供核对文件一致性；它不替代运行复现。

## 如何查看

先阅读 [业务说明](scenario/00_business_brief.md)，再对照 [脱敏场景](scenario/03_demo_fixture.json)、[输出约束](scenario/04_decision_response_schema.json) 和 [实际运行记录](evidence/validation-results.json)。当前仓库没有启动命令，不能克隆后直接运行真实 Agent。

已有企业级多轮可视化界面在开发者本机 CogSeed 中运行；其运行时、界面发行包以及可导入资产尚未包含在这里。本仓库未复制 CogSeed 产品源码、登录信息、API 密钥或其他用户会话。

## 提交前仍需完成

1. 交付老师可独立打开的应用版本，说明运行环境、模型配置和授权方式。
2. 导出并核验真实 Agent、Skill、RAG 资产；建立并验证可复用工作流。提示词文档不能代替实际资产。
3. 在另一环境完成导入、运行及五类用例复现，记录成功项和失败项。
4. 冻结提交 commit；补齐如实的自评与 AAR，标明本试点由用户与 AI 协作完成，不冒充学生独立作业。
5. 完成 EduSeed 提交，再由教师账号打开同一版本、核验并给出评审。

试点截止时间：2026-12-31 23:59（北京时间）。

## 使用边界

模型仅提出待负责人确认的建议，不执行调人、派单、绩效修改或规则发布。场景内预设根因用于测试响应和证据约束，不构成对真实业务的因果验证。AI 输出即使通过结构校验，也仍需核对业务正确性。
