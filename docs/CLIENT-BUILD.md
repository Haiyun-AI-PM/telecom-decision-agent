# 可视化客户端兼容性与构建状态

本作品在 CogSeed 内运行，使用 CogSeed 已配置的模型；不需要独立网页服务器、浏览器手动接力或作品专用 API Key。

## 已确认

- 本机 CogSeed 开发版可以打开“电信经营决策应用”，包含连续历史、自由追问、增员假设、人员不可用调整、依据展开与图表。
- 2026-09-21 再次打开真实应用，可见 11 轮历史和操作入口。
- 已通过项目的 `package:dev:mac` 命令生成 Apple Silicon 试用客户端，产品名 `CogSeed Dev`，代码版本 `f79719c75b057710d34932f32d98b29281129898` 加本地可视化修改（dirty=true）。这不是正式发布版。
- 已核对打包产物中的可视化 JS、CSS、HTML 与当前本机源文件一致。

## 尚未达到可分发验收

`verify:package:dev:mac` 未通过：其必需文件清单要求 `src/main/util/migrate-source-data-root.cjs`，但当前源码也已不存在该文件，需核实构建验证清单与当前迁移实现的一致性。不能忽略失败并标记试用包可交付。

当前没有经过教师独立安装、登录、导入和运行验证的客户端发行包，因此未上传二进制或声称已发布。试用包未签名；Windows、Intel Mac、生产网页版尚未完成本作品兼容性验证。

## 教师如何判断版本可用

在目标客户端导入资产并运行首问后，确认实际响应显示经营判断卡片，且有“打开经营决策应用”入口。进入后发起一个新的追问，等待真实结果追加并重新打开会话确认保存。

如果没有该入口，说明仍需把可视化改动集成到教师使用的客户端版本；复制 Agent JSON、配置新的 API Key 或打开参考 HTML 都不能解决这一版本差异。

## 交付边界

仓库已包含可通过现有界面导入/重建的业务资产及验证步骤，但不宣称原生可视化工作流、跨账号一键安装、EduSeed 一键启动或教师评审已完成。以教师自己的实际验证记录为准。
